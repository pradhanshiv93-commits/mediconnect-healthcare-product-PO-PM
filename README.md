# MediConnect-Heathcare Product Portfolio 
A Product product management portfolio showcasing PM, BA, and PO deliverables for telehealth appointment & 
case coordination platform aimed at improving healthcare access for patients managing chronic conditions.

## About this project 
This is a self-driven case study built to demonstrate end-to-end product 
thinking — from problem discovery to requirements, backlog, and metrics — 
using a healthcare domain scenario
